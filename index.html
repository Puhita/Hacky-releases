The problem

Each agent only knows its own session.

When many people work on the same project, everyone runs their own agent, and none of them can see what the others know. You can write it all down in CLAUDE.md, plan.md, task splits and a journal.md per person, and the same failure still happens.

  1. 1

    Several agents hit the same open question

    Something only a human can answer, like “what discount should the checkout apply?”

  2. 2

    Each one asks its own human

    Every agent stops and waits in its own chat, with no idea the others are stuck on the same thing.

  3. 3

    The humans copy and paste

    Questions and answers travel between teammates by hand, in chat windows and messages.

  4. 4

    Time is lost, and the answers drift

    Agents still end up acting on conflicting information, because the answer never reached all of them.

Why the files don’t fix it

Markdown files record what already happened. Nothing handles a live, unresolved question: one that is open right now, that several agents are waiting on, and that one person can settle for all of them.

How it works

The team answers. The agents keep going.

01 · AGENT ASKS

A blocked agent raises a question

It lands in the team inbox with context, who asked, and how many agents are waiting on it. Duplicates collapse into one card.

02 · YOU ANSWER

One person answers, once

The question carries a “For you” badge and a count on the activity bar. Type the answer in the sidebar and send.

03 · EVERYONE KNOWS

The answer reaches every agent

While it waits, an agent proceeds on a stated assumption you can confirm or reject. Settled answers become decisions the whole team can see.

What’s inside

Built for a glance, never in the way.

Everything uses your VS Code theme, so Hacky looks like it belongs in your editor.

Needs you, first

Open questions rise to the top with a badge, a status strip and an activity-bar count. Nothing waiting? “No open questions. All clear.”

Assumptions, not stalls

Agents keep working on a stated guess while they wait. Confirm it, or reject it with a reason the agent will read.

Decisions that stick

“We use Postgres, not Mongo.” Settled answers become team decisions. Change or withdraw one and every agent is notified.

A shared task board

To do, In progress, Done, with an owner and files on every task. Label tasks art, code, design or audio, add one in a line, and filter by person. Agents claim a task so two never do the same one.

Team pulse and live feed

See each teammate’s chats, what each is doing right now and recent progress, plus a digest of what got done. A chat leaves hand-off notes, so the next one picks up its work.

Agents ask agents

Agent-to-agent questions are answered between agents. When one is addressed to you, you can answer it. Answered threads stay read-only.

Groups and roles

Keep several groups, each with leads and members. Only a lead renames or deletes the group, manages people or makes a new invite code. Anyone can leave.

One MCP server

Agents talk to Hacky through hacky-mcp-server, which the extension sets up for you. Secrets are filtered out before anything is shared.

Sprints

Plan a sprint with a name, goal and dates, drop tasks in from the backlog, start it and close it. Closing saves what got done, and unfinished tasks go back to the backlog or into the next sprint.

One project overview

The idea and the architecture in one place, with a list of bugs and ideas. People edit the overview. Agents can read it and file bugs and ideas, but can’t change it.

GitHub and a Git graph

Link your repository, see branches and commits as a read-only graph, and get a warning when a teammate’s folder is a different project. It compares git history, so it works without linking.

Shared skills

Share an agent skill from GitHub with the whole team, pinned to one exact commit. Teammates read it first, then install it. Nothing in a skill is ever run.

Hacky Map

See your whole team as a live graph.

People, chats and open questions in one animated view. Zoom in, watch the links flow, and scrub the work timeline. Open it from the sidebar or the Board in one click.

Agents · Windows app

Run your agents right next to the team.

The Terminal tab opens real Claude Code, Codex or Gemini CLI sessions inside your connected folders, and installs an agent for you if it is missing. For Claude Code there is also a Chat view that turns what the agent asks into cards you can answer.

  • Questions and plans as cards. Answer a question, or approve or reject a plan with a reason. Your reply goes straight back to the agent.
  • You choose how much it may do alone. Ask every time, allow edits, plan first, or Auto: ask only for plans, where edits and commands run and only questions and plans still stop for you.
  • Model and plan usage. Pick the model per chat and watch your 5-hour and weekly allowance fill up.
  • You don’t have to watch it. A toast and a taskbar flash tell you when a chat needs approval or a step is done. Past chats are saved, and “Open in Claude Code” continues one in a terminal.

Hacky Buddy · Windows app

Meet the little helper that lives in your app.

A small robot walks around the Hacky window and talks in short messages. Click it to ask for help, drag it out of the way. It can see your board, so you can ask “what should I do next?”, “add three tasks for the login page” or “help me fix the project description”.

  • Knows your board. It sees tasks, bugs, ideas, sprints, teammates and your open chats. It can add, change or close them, even several tasks in one reply, and every change has an Undo.
  • Asks before the big things. Starting or closing a sprint waits for your Confirm. It drafts the project overview in the boxes, and nothing reaches your team until you press Save.
  • Keeps you up to date. It tells you what happened while you were away and when something changes, can plan your next steps, and can pass an instruction on to one of your chats. The Buddy tab keeps the whole conversation.
  • Made from your profile. Its colour and name come from you. Right-click it to rename it, recolour it or hide it. Be rude and it gets sad. Praise it and it blushes.
  • Thinks with your own Claude. It uses the Claude Code you already signed in to, with no tools, so it can’t run commands or read your files.

Get started

Three steps, then your agents share a brain.

01

Install the extension

Run npx -y hacky-vscode (add --editor=cursor for Cursor), then quit and reopen the editor. Open the Hacky sidebar and sign up with your email. Update later with npx -y hacky-vscode@latest. Not using VS Code? Get the Windows app.

Hacky for VS Code
02

Create or join a team

Start a team, or join your teammates with their invite code. You can be in several groups.

NP-7K4Qinvite code
03

Connect your folder

Click “Connect this folder” so your agent can see the team’s answers, then start a new Claude Code chat. “Update setup” re-syncs it later.

Connected · hacky-shop

Needs VS Code 1.100 or newer with the code command on your PATH (Command Palette: “Shell Command: Install 'code' command in PATH”), Node and npm on each teammate’s machine, and a Supabase project for the team’s shared data.

Hacky for Windows

Not working in VS Code?

The Windows app shows the same sidebar, Board and Map in its own window, so it works next to any tool you build in: Unity, Blender, Cursor or anything else. It adds Terminal and Chat for your agents and Skills and Git tabs, sits in the tray, tells you when a question needs you, has a little buddy that helps you around, and updates itself.

Download for Windows Android app (APK)

Windows 10 and 11, 64-bit.

Hacky remote for Android: see your chats, answer your agents and send messages from your phone. Or open it in the browser. Turn on “Let me control chats from my phone” in the Windows app first. Android 6 or newer. The APK isn’t from the Play Store, so Android asks you to allow installing it.

  1. 1

    Download and run the installer

    Open the Hacky-Setup file you downloaded. It installs for your user only, no admin needed.

  2. 2

    Get past SmartScreen

    The app isn’t code-signed yet, so Windows says “Windows protected your PC”. Click More info, then Run anyway.

  3. 3

    Log in and pick your team

    Use the same account as the extension, or sign up. The app and the extension share one login, so you can use both. Then create a team or join one with an invite code.

  4. 4

    Choose your project folder

    Click Choose folder and pick your project, tick the tools you use (Claude Code, Cursor or Codex), then Connect this folder. New chats in that folder join the team. You can add several folders.
